# نسخه اندروید (APK) — حسابداری رستوران سنتی گلستان

## روش ۱ (پیشنهادی): ساخت خودکار APK با GitHub Actions
1. در github.com وارد حساب خود شوید ← New repository (مثلاً `golestan-pos`) ← Create repository.
2. گزینه‌ی **uploading an existing file** را بزنید و همه‌ی فایل‌ها و پوشه‌های داخل این زیپ را (از جمله پوشه‌ی `.github`) بکشید و رها کنید ← Commit changes.
   - اگر پوشه‌ی `.github` آپلود نشد: Add file ← Create new file ← در کادر نام بنویسید `.github/workflows/android.yml` و محتوای فایل `android.yml.txt` را در آن بچسبانید ← Commit.
3. تب **Actions** ← «Build APK». اگر خودکار اجرا نشد، Run workflow را بزنید. حدود ۵ تا ۱۰ دقیقه صبر کنید.
4. بعد از تیک سبز، وارد همان اجرا شوید و پایین صفحه در بخش **Artifacts** فایل `golestan-apk` را دانلود کنید. داخل زیپ آن `app-debug.apk` است.
5. فایل را روی گوشی نصب کنید (اجازه‌ی «نصب از منبع ناشناس» را بدهید).

## روش ۲: PWABuilder
GitHub Pages را برای مخزن فعال کنید (Settings ← Pages ← Branch: main، پوشه‌ی `/www` یا ریشه پس از انتقال فایل‌های www)، سپس آدرس را در pwabuilder.com وارد کنید و Android package را بگیرید.

## نکات
- ذخیره‌ی PDF و اکسل در اپ اندروید از طریق منوی اشتراک‌گذاری (Share) انجام می‌شود؛ «ذخیره در فایل‌ها / Drive / واتساپ» را انتخاب کنید.
- اطلاعات روی همان گوشی ذخیره می‌شود. با «نسخه پشتیبان» در تب «روزها» نگه‌داری کنید. حذف برنامه یعنی پاک شدن اطلاعات.
- فونت‌ها و ساخت PDF برای بار اول به اینترنت نیاز دارند و بعد ذخیره می‌شوند.
- فایل ساخته‌شده نسخه‌ی debug است و مستقیم نصب می‌شود. برای انتشار در مارکت‌ها باید نسخه‌ی release با امضای شخصی ساخته شود.
